# GAHKCHA demo images

Place future local demo assets here, using the filenames referenced by
`frontend/src/gahkcha/challenges.ts`. The current `gahkcha-tile-*.jpg` files
are 320 px, local tile derivatives: all 16 paths are distinct, but several use
the same supplied source image until a fuller demo set is available. The modal
only inserts and fetches them when a challenge opens, and displays a neutral
“Demo” tile when an image cannot be loaded.

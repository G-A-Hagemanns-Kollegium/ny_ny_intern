The body is rendered with |markdown, which returns an already-safe string (core.markdown). Do NOT add |safe here. A post has no headline: the author heads the card, the way every other feed these residents use already works, and the way people wrote them anyway once titles stopped being a restatement of the first line. The category chip carries "what is this about" instead, and it is filterable. In the list the whole card is tappable: the TIMESTAMP is the post's permalink, stretched over the card with a CSS pseudo-element (.is-clickable below), so it stays one real link — keyboard reachable, right-clickable, no JavaScript. It used to be the title link; the timestamp is what every social feed uses for the same job, and the author's name would have read as a link to a profile that does not exist. Controls that must stay clickable are raised above it. {% endcomment %}

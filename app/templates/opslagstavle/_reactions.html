{% comment %} One row per PERSON, not per emoji. Comma-joining a group onto one line was unreadable as soon as a post got popular: fifteen names wrapped into a paragraph you had to parse rather than scan. A row each turns it into a list you scroll, which is what the panel is for. The emoji repeats on every row rather than heading a section, so it is still beside the name you are looking at once the list is long enough to scroll. Order comes straight from core.reactions.reaction_rows -- most-used emoji first, and within a group the order people reacted in -- so the panel matches the pills above it. {% endcomment %}
